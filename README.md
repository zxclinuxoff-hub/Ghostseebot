# GhostSeeBot (aiogram 3) — Telegram Business бот

Единая подписка «Всё включено»: удалённые и изменённые сообщения, временные фото («сии»), команды.
Тариф: 7 дней бесплатно → 1 мес — 40⭐, 3 мес — 100⭐, 1 год — 360⭐. Рефералы, рулетка, партнёрка, админ-панель, логи.

## Структура
```
main.py                  вход: webhook-сервер (aiohttp) или long polling, обработчик ошибок → админу
schema.sql               таблицы Supabase (префикс gs_)
assets/                  banner_start.jpg — баннер /start (главное меню без баннера, текстом)
bot/config.py            настройки, тарифы
bot/db.py                клиент Supabase
bot/keyboards.py         inline-клавиатуры
bot/texts.py             справка по командам
bot/services/            users · billing · referrals · roulette · scheduler · biz (Business API) · logs
bot/handlers/            start (меню, кабинет, рефералы, рулетка, настройки) · payments · admin · business · extras (донат, настройка команд, .afk-исключения)
bot/commands/            engine (реестр) · tools (все .команды)
```

## Установка
1. **Supabase** → SQL Editor → вставь `schema.sql` → Run. Если база уже работает, достаточно выполнить `migrations/001_donate_and_afk_exclusions.sql`.
2. **GitHub**: залей проект (с сохранением папок).
3. **Render** → New → Web Service → репозиторий. Build: `pip install -r requirements.txt`, Start: `python main.py` (или Blueprint из `render.yaml`).
4. **Environment** (см. `.env.example`): `BOT_TOKEN`, `ADMIN_IDS`, `SUPABASE_URL`, `SUPABASE_KEY` (secret-ключ), `WEBHOOK_BASE_URL` (необязательно: на Render берётся автоматически из RENDER_EXTERNAL_URL), `WEBHOOK_SECRET`, `CHANNEL`, `BOT_USERNAME`.
5. **Канал**: добавь бота **админом** в @ghostsee_channel — иначе проверка подписки для рефералов не работает.
6. **cron-job.org**: GET `https://ТВОЙ-СЕРВИС.onrender.com/health` каждые 10 минут (на бесплатном Render сервис засыпает, пинг его будит и держит фоновые задачи).
7. @BotFather → Bot Settings → **Business Mode** включить. Потом в Telegram: Настройки → Автоматизация чатов → ввести @ghostseebot → Добавить (права: читать, отвечать, удалять, менять имя).

Локально без вебхука: оставь `WEBHOOK_BASE_URL` пустым — запустится long polling.

## Админ-панель (`/admin`, только ADMIN_IDS)
`/give @user 7d|3m|1y` · `/take @user [30d]` · `/ban` `/unban` · `/user` · `/stats` · `/logs [level] [N]` · `/broadcast` (текст/фото + кнопки, предпросмотр) ·
`/partner_add ID процент [код]` · `/partners` · `/payout код звёзды` · `/refund USER_ID CHARGE_ID`

## Рефералы
2 друга → +3 дня · 5 друзей → +8 дней всего (ещё +5) · далее +1 день за каждого. Засчитывается, только если друг запустил бота по ссылке и подписан на канал.

## Рулетка (раз в 24 ч)
+1 день 70% · +2 дня 10% · +3 дня 5% · скидка до 50% на год 7% · скидка до 20% на 3 месяца 8%.

## Партнёрка
`/partner_add` создаёт ссылку `?start=p_КОД`. С каждой покупки Stars привлечённых пользователей партнёру начисляется процент; выплата вручную (`/payout`).

## Чего нет и почему
- **Трекер прочтений** — Telegram не присылает ботам события «собеседник прочитал», технически невозможно.
- **`.pinf`, `.spinf`, `.plink`, `.clonep`** — слежка за профилями и фишинговые ссылки, не реализовано.



## Поддержать разработчика (донат Telegram Stars)

Кнопка «⭐ Поддержать разработчика» в главном меню. Суммы: 1, 2, 5 или 10 ⭐. Бот выставляет настоящий счёт в валюте XTR.

- Донат **не продлевает подписку** и не связан с тарифами: отдельный префикс payload (`donate:`) и отдельная таблица `gs_donations`.
- Засчитывается только по событию `successful_payment`. Нажатие кнопки или открытие счёта доната не засчитывают.
- Повторная доставка того же платежа не обрабатывается дважды: ключ — `telegram_payment_charge_id` (первичный ключ таблицы).
- В `pre_checkout` проверяются сумма, валюта и тип платежа.

## Настройка команд и исключения для .afk

Кнопка «⚙️ Настройка команд» в главном меню. Сейчас есть настройка `.afk`: список **исключений**. Пользователям из списка бот не отправляет AFK-ответ и не запускает повторный ответ. Для остальных собеседников поведение `.afk` не меняется, режим не отключается глобально.

- Исключения привязаны к владельцу Business-аккаунта и хранятся в `gs_afk_exclusions` (ключ `owner_id + excluded_id`, дубликаты невозможны).
- Добавить можно по Telegram ID (5–15 цифр). Удалить — кнопкой из списка. Список постраничный.
- Меню доступно только при активной подписке, все проверки делаются на сервере по текущему пользователю.
- Новую настройку команды можно добавить в реестре `CMD_SETTINGS` в `bot/handlers/extras.py`.
- Команды в чате: `.afk_ex` добавляет собеседника этого диалога в исключения, `.afk_unex` возвращает ему автоответ. Список кэшируется на 20 секунд; изменения сбрасывают кэш сразу.

## Тесты

Бизнес-логика доната и исключений проверяется без реальных платежей и базы: `python -m pytest -q` (нужен pytest, в `requirements.txt` он не входит).

## Статистика

`/stats` (только ADMIN_IDS) показывает пользователей, подписки, доход, рефералы и донаты: сумму, количество и топ поддержавших.

## Логи Business-чатов

Сообщения, правки и удаления логируются в форум-группу из `LOG_CHAT_ID` по отдельным темам собеседников. Привязка `user_topics` и временный буфер `temp_messages` хранятся в Supabase/PostgreSQL; SQLite не используется. Бот должен быть администратором группы с правом управления темами. Включи Topics/Темы в настройках супергруппы.

## EXIF фото

Ответь командой `.exif` на фото или оригинал изображения, отправленный как файл. Отчёт уходит владельцу Business-аккаунта в личку; GPS-координаты, если они есть в EXIF, также отправляются туда как точка карты. Telegram обычно удаляет часть метаданных у обычных фото, поэтому оригинал как документ даёт лучший шанс. Команда не извлекает данные, которых в файле нет.

## Ограничения Telegram

Журнал может отмечать только пересланные сообщения, которые пришли в Business-чат с доступным Telegram `forward_origin`. Telegram не сообщает боту, когда пользователь пересылает любое сообщение из закрытого чата в другой чат, поэтому универсальный Anti-Forward Trace технически невозможен. Реальные реакции и IP посетителей сторонних ссылок тоже нельзя достоверно подделать/узнать средствами Telegram Bot API.


## Прозрачные ссылки-маячки

` .canary название ` создаёт ссылку на странице сервиса, ` .canary_stats ` показывает клики. При открытии сохраняется только токен и время. IP-адрес, ОС, провайдер и отпечаток устройства не собираются. Для работы нужен webhook-режим и `WEBHOOK_BASE_URL`/`RENDER_EXTERNAL_URL`.
